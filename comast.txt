  <h5 class="card-header primary_color secondary_bg_color">Introduction to Economy API</h5>
  <div class="card-body">
    <!--h4 class="card-title">Title</h4-->
    <p>Economy API provides a very simple interface by which the user can download the Company's Profile, Standalone and Consolidated data of one or more Companies.</p>
    <p>One can download either latest data of multiple companies or last 5 years data of a single company. 3 hits shall be deducted per company.</p>
    <p>To use this facility, you just need the Passkey and valid Company Codes. <a href="/kommon/bin/sr.php?kall=wdltxt&fnm=comast.txt"><i>Click here</i></a> to download the Company Master.</p>
    <p>Output shall be in the form of a '.zip' file named 'Economyapi_yyyymmdd_hhmmss.zip'. The '.zip' file shall have one or more '.txt' files named as per the requested company. For Example :
    <ul><li>If the user has requested the latest data of 'Reliance Industries Ltd.' and 'Tata Motors Ltd.' the filename shall be '196667_RELIANCE_INDUSTRIES_LTD__latest_username.txt' and '248093_TATA_MOTORS_LTD__latest_username.txt'.
    <li>If the user has requested the last 5 years data of 'Reliance Industries Ltd.' the '.txt' filename will be '196667_RELIANCE_INDUSTRIES_LTD__last5yr_username.txt'.
    <li>All errors are reported inside a file named 'ERROR.txt'. All 'Invalid credentials/usage agreement policy authorisation/NO live subscription/Invalid Company Codes' etc. are reported in this file.
    </ul>
    </p>
    <p>For more information as to how to download the data refer to the <a href="?section=example_php"><i>Examples</i></a> section.</p>
